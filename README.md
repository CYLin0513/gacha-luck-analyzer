# 🎲 Luck Lab — Gacha Luck Analyzer

> ⚠️ **這只是一份 GenAI / Vibe Coding 課程實驗作業，並非嚴謹或生產級的工具。**

一個輸入「機率、抽數、中獎數」來計算「你到底有多衰」的二項分佈網頁分析器。

## 📌 摘要
* **功能**：計算期望值、Z-score、運氣百分位，並以 Monte Carlo 模擬 50,000 次抽卡結果分佈。
* **技術**：純 HTML / CSS / Vanilla JS（全整合於單一 `index.html`，部署於 GitHub Pages）。
* **限制**：僅計算獨立機率事件，**不支援**保底或機率遞增等機制。
